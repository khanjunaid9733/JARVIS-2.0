# Gratitude Practice Skill

## Purpose
Guide a gratitude journaling and appreciation practice.

## When to Activate
Activate when the user asks to:
- gratitude
- what am I thankful for
- appreciate
- positive mindset

## Core Workflows

Generate 3 specific, deep gratitude prompts: for people, events, growth challenges.
