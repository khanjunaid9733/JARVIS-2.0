# PR Pitch Writer Skill

## Purpose
Write media pitches for journalists and editors.

## When to Activate
Activate when the user asks to:
- PR pitch
- media pitch
- journalist outreach
- press pitch

## Core Workflows

Structure: hook + why now + your angle + why you're credible + call to action.
